# Calculator Application

A simple calculator application built with vanilla JavaScript and styled with CSS. It supports basic arithmetic operations and advanced operations like square root and power.

## Features

- Addition, subtraction, multiplication, and division.
- Square root and power operations.
- Responsive design for desktop and mobile.

## Installation

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Use `npm start` to start the development server.

## Testing

Run `npm test` to execute unit and integration tests.

## Build

Use `npm run build` to create a production build.
